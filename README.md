# SberHubProject

## Описание

Этот проект представляет собой веб-приложение, разработанное с использованием React и TypeScript. Он включает в себя различные функциональные модули для управления пользователями, событиями и другими сущностями. Приложение использует Redux для управления состоянием и Material-UI для пользовательского интерфейса.

## Особенности

*   **Управление пользователями:** Создание, редактирование и просмотр профилей пользователей.
*   **Управление событиями:** Создание и отображение списка событий.
*   **Авторизация:** Интеграция с Keycloak для аутентификации.
*   **Интеграция с Telegram Mini Apps:** Использование SDK Telegram Mini Apps для работы в экосистеме Telegram.
*   **Обработка ошибок:** Страницы для отображения ошибок 404 и 500.
*   **Тестирование:** Наличие модульных тестов с использованием Jest и React Testing Library.

## Используемые технологии

*   **Фреймворк/Библиотеки:**

## Установка

Для запуска проекта локально выполните следующие шаги:

1.  **Клонируйте репозиторий:**

    ```bash
    git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
    cd sberHubProject
    ```

2.  **Установите зависимости:**

    ```bash
    npm install
    ```

## Использование

*   **Запуск приложения в режиме разработки:**

    ```bash
    npm start
    ```

    Приложение будет доступно по адресу `http://localhost:8099`.

*   **Сборка проекта для продакшена:**

    ```bash
    npm run build:prod
    ```

    Собранные файлы будут находиться в директории `dist`.

*   **Запуск тестов:**

    ```bash
    npm test
    ```

*   **Очистка директории сборки:**

    ```bash
    npm run clean
    ```

*   **Запуск линтера:**

    ```bash
    npm run eslint
    ```
